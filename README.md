## 🌐 วิธีนำขึ้นโฮสติ้งฟรีบน GitHub Pages (Domain GIT ฟรี 100%)

คุณสามารถนำเว็บนี้ขึ้นอินเทอร์เน็ตได้ฟรีตลอดชีพผ่าน **GitHub Pages** ตามขั้นตอนง่ายๆ ด้านล่างนี้ครับ:

### ขั้นตอนที่ 1: สร้าง Repository บน GitHub
1. ล็อกอินเข้าเว็บ [https://github.com](https://github.com)
2. กดปุ่มเครื่องหมายบวก **`+`** ที่มุมขวาบน แล้วเลือก **New repository**
3. ตั้งชื่อ Repository เช่น `dome-break-tak`
4. ติ๊กเลือกเป็น **Public**
5. กดปุ่ม **Create repository**

### ขั้นตอนที่ 2: อัปโหลดไฟล์ขึ้น GitHub
เปิด Terminal หรือ PowerShell ที่โฟลเดอร์ `dome-break-tak` แล้วรันคำสั่ง:
```bash
git init
git add .
git commit -m "Launch Dome Break Tak website"
git branch -M main
git remote add origin https://github.com/<ชื่อ-username-ของคุณ>/dome-break-tak.git
git push -u origin main
```
*(หากไม่ถนัดคำสั่ง สามารถเปิดหน้าเว็บ GitHub Repository แล้วกดปุ่ม **Add file -> Upload files** แล้วลากโฟลเดอร์และไฟล์ทั้งหมดเข้าไปอัปโหลดผ่านเว็บได้เช่นกันครับ)*

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages
1. ในหน้า Repository ของคุณบน GitHub ให้คลิกแท็บ **Settings** ด้านบน
2. เมนูด้านซ้ายคลิกที่หัวข้อ **Pages**
3. ตรงหัวข้อ **Branch** ให้เลือกเป็น `main` และโฟลเดอร์เป็น `/(root)`
4. กดปุ่ม **Save**
5. รอประมาณ 1 นาที GitHub จะสร้างลิงก์เว็บไซต์ให้ฟรี เช่น:
   👉 **`https://<ชื่อ-username>.github.io/dome-break-tak/`**
